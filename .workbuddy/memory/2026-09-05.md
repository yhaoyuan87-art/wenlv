# 2026-09-05 工作日志

## 长春地铁文旅平台（changchun-metro-demo）— 白天/夜间双主题

**成果**：为 Vue-React 3D 项目完成白天/夜间双主题切换系统，已推送至 GitHub（commit `83e06e9`）。

### 技术实现要点
- **语义化 CSS 变量主题层**：`:root` 为夜间默认，`html.theme-light` 覆写。新版组件全部改用语义变量（`--bg`/`--panel`/`--accent`/`--scene-bg` 等），不再硬编码色值。
- **新增 `src/theme/theme.js`**：主题解析（URL > localStorage > 系统偏好）、应用（切 class + meta theme-color）、持久化。
- **useStore**：新增 `theme` 状态 + `setAppTheme`/`toggleTheme`，同步 URL `?mode=`。
- **TopNav**：新增 🌙/☀️ 分段胶囊切换按钮。
- **3D 场景联动**：CityScene/MetroScene 的背景 + 雾与 `--scene-bg`/`--scene-fog` 联动，新增 `setTheme()`。
- **新增 `--accent-grad` 变量**：移动端选中态/主按钮由它驱动，白天模式用加深深蓝，保证文字对比度。

### 踩过的坑（重要）
1. **`setTheme` 键名冲突（真 bug）**：项目原有一个 `setTheme(themeId)` 控制「路线主题」（2D 地图主题卡），与新外观 `setTheme(theme)` 重名。JS 对象字面量只保留后一个，导致 `toggleTheme()` 实际调的是路线 setter，外观切换失效。**修复**：外观改名为 `setAppTheme`，路线主题保留 `setTheme`。
2. **URL 参数冲突**：`?theme=` 已被路线主题占用，外观主题改用 `?mode=`。
3. **headless-WebGL 验证限制**：agent-browser headless 下 WebGL RAF 动画会抢占主线程，React 组件树不提交（`.topnav` 不渲染），但 CSS 变量正常解析。改用 `eval` 读 CSS 变量 + 截图对比两主题背景色来验证，可靠。
