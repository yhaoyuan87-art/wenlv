### 踩过的坑（重要）
1. **`setTheme` 键名冲突（真 bug）**：项目原有一个 `setTheme(themeId)` 控制「路线主题」（2D 地图主题卡），与新外观 `setTheme(theme)` 重名。JS 对象字面量只保留后一个，导致 `toggleTheme()` 实际调的是路线 setter，外观切换失效。**修复**：外观改名为 `setAppTheme`，路线主题保留 `setTheme`。
2. **URL 参数冲突**：`?theme=` 已被路线主题占用，外观主题改用 `?mode=`。
3. **headless-WebGL 验证限制**：agent-browser headless 下 WebGL RAF 动画会抢占主线程，React 组件树不提交（`.topnav` 不渲染），但 CSS 变量正常解析。改用 `eval` 读 CSS 变量 + 截图对比两主题背景色来验证，可靠。

## 白屏事故与排查（2026-09-06 凌晨，commit 6ab05ff 修复）

**现象**：主题功能推送后，浏览器打开页面全白，什么都不显示。

**真正根因（两个，都是"编辑未完整落盘"造成）**：
1. **TopNav.jsx 缺 hooks 声明（白屏元凶）**：JSX 里用了 `theme`/`toggleTheme`，但 `const theme = useStore((s) => s.theme)` 两行没写进文件。运行时 `ReferenceError: theme is not defined` → React 整树卸载 → 白屏。**构建（vite build）不会报这种错**——未定义变量只在运行时炸，oxlint 也没开 no-undef。
2. **MetroScene.js 缺导入**：用了 `cssVar/hexToNumber` 但 import 行没落盘，切地铁层会炸。

**环境坑（叠加因素）**：旧的 vite dev server（PID 28960）从上一会话一直活着，**文件监听已失灵**，HMR 一直在吐内存里的过期 transform（URL 带 `?t=旧时间戳`），磁盘上修好的代码根本没被服务出去。杀掉重启（`--strictPort` 固定 5173）后才生效。

**排查方法论（可复用）**：
- 白屏排查利器：往 `index.html` 临时注入 `<script>` 捕获 `window.onerror` 写入 `window.__errs` 并改写 `document.title`，agent-browser open 的输出会直接打印标题即错误。用完移除。
- `curl` 逐个模块查 dev transform（500=编译错）、查 `/node_modules/.vite/deps/*.js?v=hash` 是否 404（deps 哈希漂移会静默炸整图）。
- vite build 通过 ≠ 运行时没问题：未定义变量/运行时 TypeError 构建器不查。
- agent-browser 在 WebGL RAF 动画页面上 click/wait/snapshot 会 SIGTERM，但 `open` 和 `eval` 相对可靠；程序化点击用 `eval "document.querySelector('.theme-toggle').click()"` 代替 click 命令。
- 长驻 dev server 必须用 Bash 工具的 `run_in_background: true`，用 `(cmd &)` 子shell后台会在会话结束时被杀。
- Git Bash 下杀 Windows 进程：`taskkill //F //IM node.exe` 语法不可靠，用 PowerShell 工具 `Get-NetTCPConnection -LocalPort 5173 | Stop-Process` 最稳。

**最终验证结果（真实浏览器）**：城市层挂载 ✓（rootLen=5608、顶栏、4 Tab、canvas）、主题点击切换 ✓（dark→light class 正确翻转）、地铁层 ✓（16 站点标签渲染）。
